🎯실습 개요

바이브 코딩(Vibe Coding)은 AI 어시스턴트와 자연어로 대화하며 코드를 직접 작성하지 않고도 웹페이지와 프로그램을 완성해 나가는 실습 방식입니다. 2주차 실습에서는 Claude Code를 활용해 정적 웹사이트(메인 페이지 + 블로그)를 기획하고, Git/GitHub로 버전 관리 및 배포까지 이어지는 전체 흐름을 경험합니다.

🛠️사전 준비

아래 준비물이 갖춰져야 다음 단계인 실습 내용을 무리 없이 진행할 수 있습니다.

  • GitHub 계정 & 원격 저장소
  • Git 설치
  • Claude Code
  • HTML/CSS 기초 이해

🚀실습 내용

사전 준비를 마쳤다면, 아래 순서대로 진행됩니다
1. 기획 — README로 목차 잡기
README.md를 작성해 실습 목차(개요·준비·내용·정리)를 먼저 정리하고, 전체 페이지 구조의 뼈대로 삼았습니다.
2. 제작 — 메인 페이지 & 블로그 페이지
README의 목차를 그대로 index.html의 골격으로 옮기고, 실습 기록을 남길 blog.html을 만들어 서로 연결했습니다. 동덕여자대학교 시그니처 핑크 톤을 전체 디자인에 적용했습니다.
3. 배포 — Git 커밋 & GitHub Pages
변경 사항을 커밋해 main 브랜치에 push하고, GitHub Pages를 켜서 코드를 실제 접속 가능한 웹사이트로 배포했습니다.
4. 마무리 — 환경 커스터마이징
Claude Code의 상태줄(statusLine)을 원하는 형태로 설정하며 다음 실습을 위한 작업 환경을 정리했습니다.

🏁결과 정리

AI와의 대화만으로 기획 → 제작 → 배포로 이어지는 웹 개발 전체 흐름을 경험했습니다. 완성된 결과물은 GitHub Pages를 통해 실제 웹사이트(https://songdahee0905.github.io/vibe-week1/)로 확인할 수 있습니다. 과정 중 겪었던 시행착오와 배운 점은 블로그에 자세히 기록했습니다.
