1실습 개요

바이브 코딩(Vibe Coding)은 AI 어시스턴트와 자연어로 대화하며 코드를 직접 작성하지 않고도 웹페이지와 프로그램을 완성해 나가는 실습 방식입니다. 2주차 실습에서는 Claude Code를 활용해 정적 웹사이트(메인 페이지 + 블로그)를 제작하고, Git/GitHub로 버전 관리 및 배포까지 진행합니다.

2사전 준비

  • GitHub 계정 및 원격 저장소(vibe-week1) 생성
  • Git 설치 및 로컬 저장소 연결
  • Claude Code(터미널 AI 어시스턴트) 설치
  • HTML/CSS에 대한 기초 이해

3실습 내용

  • README.md 작성 및 실습 목차 정리
  • 메인 페이지(index.html) 제작 — 동덕여자대학교 시그니처 핑크 톤 적용
  • 블로그 페이지(blog.html) 제작 및 메인 페이지와 연동
  • Git으로 변경 사항 커밋 후 GitHub main 브랜치에 push
  • GitHub Pages를 활성화하여 실제 웹사이트로 배포
  • Claude Code 상태줄(statusLine)을 원하는 형태로 커스터마이징

4결과 정리

AI와의 대화만으로 기획 → 제작 → 배포까지 이어지는 웹 개발 전체 흐름을 경험했습니다. 완성된 결과물은 GitHub Pages를 통해 실제 웹사이트(https://songdahee0905.github.io/vibe-week1/)로 확인할 수 있으며, 앞으로 각 페이지의 콘텐츠를 계속 채워나갈 예정입니다.
